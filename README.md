# WebTextScraper

## 1. Project Overview
WebTextScraper is a full-stack web application developed using React, Spring Boot, and JSoup to extract clean, readable text from websites.

## 2. Key Features
- Extracts readable text from website URLs.
- Removes unwanted HTML elements.
- Preserves headings, paragraphs, and relevant content.
- Provides one-click text copying.
- Offers a clean, responsive user interface.

## 3. Tech Stack
- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Java 25, Spring Boot 4.1.3
- **Web Scraping:** JSoup
- **Build Tool:** Maven
